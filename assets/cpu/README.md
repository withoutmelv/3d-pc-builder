# Ryzen 7 9800X3D 参考模型

通过 Blender 5.2.2 和本地 blender-mcp 创建，依据用户提供的 CPU 正反面合图。未复用 assets 下的 Sketchfab CPU 模型，也没有把整张照片贴在方块上。

## 交付

- `cpu-9800x3d.blend`：可编辑模型、灯光、相机和打包参考图。
- `cpu-9800x3d.glb`：独立 CPU 模型，供 Three.js 加载；无相机、灯光和参考图。
- `previews/hero.png`、`front.png`、`back.png`、`edge.png`：Blender 实际渲染。
- `model-manifest.json`：尺寸约定、触点数量和模型统计。
- `validation.json`：Three.js 加载及几何检查结果。
- `../../scripts/blender/build_cpu.py`、`render_cpu.py`：依次在 Blender Python 环境中执行的生成/渲染脚本，当前路径指向本项目。

## 结构及精度

模型包含分层基板、上下两个真实半圆定位槽、金属顶盖及其八处边缘凹口、底部凸缘、接缝、周围贴片元件、两面的金色定位三角、顶盖文字和背面平面 LGA 触点。CPU 作为一个装机部件整体拿放，顶盖和基板不作为用户可拆部件。

基板采用 40 × 40 mm 的建模尺寸，厚度 1.1 mm，顶盖最高 Z=3.25 mm，触点最低 Z=-0.66 mm。图片未提供侧视和实测尺寸，因此这些高度是近似值，不是制造规格。

背面建立了 1696 个视觉触点，不宣称等同于真实 AM5 的完整触点数量、网络或针脚分配。矩阵图形是不可扫码的装饰性近似；字样按参考图重建，字体、轮廓及微观表面纹理并非扫描级复刻。没有建模芯片内部晶粒或真实电路。

## 装机接入

与教程的 CPU 朝向、防呆与锁定分离原则一致。模型提供三个定位节点：

- `ANCHOR_CPU_SEAT`：触点底面中心。
- `ANCHOR_THERMAL_CONTACT`：金属顶盖中心，可用于硅脂/散热器接触定位。
- `ANCHOR_ORIENTATION_TRIANGLE`：金色定位角。

根节点为 `CPU_9800X3D`。Blender +Z 为顶盖面、+Y 为正面图上方，定位三角在 -X/+Y 角；GLB 转换为 +Y 顶盖面、-Z 上方，定位三角在 -X/-Z 角。导出对象坐标为米。

未来与主板接入时，需要将 CPU 底面锚点对齐插座落位点，并重新校准原主板近似插座的限位凸起、压盖开口和接触高度；未做穿插检查前不能声称已经机械适配。此轮未替换网页现有 CPU，也未修改自由操作或硅脂限制规则。

参考图保存在 `reference/front-back.jpg`，只用作建模依据；图像与品牌的权利状态不因重建模型而改变。本文件不构成授权证明。
