## 接入方式

`web/src/three/detailed-models.js` 通过 GLTFLoader 加载资产。Vite 输出带哈希的模型文件，无需复制 Blend、参考照片或预览图到公开目录。模型完成加载后才创建工作台；异步加载期间的最新装配状态会在创建时应用，离开页面会取消场景创建。

源模型使用米，运行时转换成现有工作台的毫米。静态网格按材质合并，每个模型实例拥有独立几何及材质，货架合批、替换配件和销毁放置预览不会误释放另一实例。主板压盖、压杆、A2/B2 卡扣及显卡卡扣保留独立可动节点；CPU、内存的定位角和真实缺口保留。散热器本体、两个风扇、四个钢丝扣和安装支架分开接入，仍由现有状态机控制。

机箱按右侧朝下摆放，后部朝 -X；CPU 落点为主板局部 `[7,4.6,-62]`，内存 A2/B2 为 `[75/95,7,-62]`。前风扇抬高以避开高内存，保留硅脂和保护膜等原有安装限制。拾取目标、安装预览、供电接口及碰撞占地同时调整。

## 教学简化与边界

- 初次接入按类别复用参考外观；2026-09-22 已改为下文记录的型号差异化外观。原价格和兼容性示例参数未改为真实商品报价。
- 原资产不是相互匹配的厂商 CAD。为对齐机箱后开口、显卡挡板与防呆键，运行时将主板第一 PCIe 槽及卡扣向 +X 校准 36 mm；没有覆盖原 GLB 或 Blend。
- 状态机仍使用四个角落主板固定点，未新增其余五个独立螺丝操作。
- RTX 4090 较厚，机箱前四片扩展挡板分为两组，复用原来的两组拆装动作。其余三片保留在机箱上。
- 主板第一 M.2 散热盖预先移开，使现有斜插、下压及固定动作可直接使用；其他两块盖板保留，本轮未新增拆盖动作。
- AM5 参考主板（board-a5 / board-large）使用一体式 I/O，新选配不生成独立挡板。旧存档读取时移除这一过时附件；其他主板的独立挡板教学继续保留。
- 旧默认侧板停车位置会映射到新安全位置，仅在读取返回值中兼容，不批量改写数据库，不重置 CPU、内存等装配进度。

## 验证

- 新增实际 GLB 加载、有限坐标、毫米尺寸、独立资源、网格合批预算验证。
- 射线确认 DDR5 底部防呆缺口仍真实贯通，并与插槽防呆键对齐。
- 验证 CPU 触点面、顶盖接触面、主板活动扣具、风扇与内存净空、显卡后挡板和闭合侧板高度。
- 回归验证自由装配状态机及旧存档迁移。
- 浏览器实际检查零件散放、主板组合、机箱组合；正式 `/builder` 页面补齐八类配件、前往推车成功。
- 未在用户的 Windows 集成显卡电脑实测 FPS，因此不作该设备的帧率保证。

原资产的源文件、建模说明和权利来源记录保留不变。此次接入不构成新的品牌授权证明。

## 2026-09-22：货架包装与型号外观

货架现在同时展示零件和外包装。17 款商品的盒面按型号印刷，盒体按品类区分大小；盒面共用纹理图集并参与静态合批。选择商品后仍送裸件到推车，不增加强制拆箱步骤。

型号映射不再只按类别返回同一个模型：

- CPU：AM5 保留原精模；AM4 使用方形顶盖、PGA 针脚和定位角。
- 主板：B650 保留参考结构；B550 改为无压盖的 PGA 插座、减少装甲；X670 增加板体扩展区及散热装甲。
- 内存：DDR5 保留 RGB 精模；DDR4 使用较矮的无 RGB 散热马甲。
- 显卡：270 / 325 / 370 mm 三种外壳及散热结构，分别搭配两个、三个、三个精模风扇；PCIe 接口和后挡板保留共用的安装基准。
- SSD：1TB 使用裸盘参考；2TB 使用带鳍片的散热结构，保留原 PCB 的接口和固定缺口。
- 风冷：150 / 180 mm 鳍片高度分别生成，底座、螺丝和独立风扇沿用教学安装基准。
- 电源：140 / 160 mm 深度、不同风扇尺寸和外壳颜色，后部固定面保持一致。
- 机箱：当前只有一款，保留已有精模。

货架、推车、工作台和 CPU / 内存 / 显卡等放置预览使用同一型号入口。切换模型只替换可视部分，保留主板活动扣具、交互目标、线缆、硅脂与螺丝节点。

这些是演示 SKU 的差异化程序模型与参考 GLB 的组合，不是每款商品的独立厂商 CAD。主板尤其仍沿用教学布局和四点固定规则，尚未按各板型重新定义所有插槽和螺丝孔坐标。原 GLB / Blend 不变。

移动速度调整为 1000 mm/s，Shift 加速为 2400 mm/s；Q 下降、E 上升，保留空格/C 升降。垂直范围扩展为 -300～2300 mm，工作台上方最低 120 mm，避免穿进台面。同方向的重复键位不会叠加速度，斜向移动归一化，失焦后停止移动。

## 当前展示范围调整

按用户确认，货架与选配列表目前每类只展示已交付的一款，共八类，推荐配置使用同一名单（`shared/stock-catalogue.js`）。这些可选配件恢复使用原交付 GLB，不使用上一轮补出的程序化替代外观；其他九款暂不展示，保留目录记录以兼容旧存档。包装、移动加速与 Q/E 升降保持可用。未来有新型号的独立资产后，再将对应型号加入展示名单。
