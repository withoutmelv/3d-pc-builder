## 已确认动作及与当前实现的差异

### 内存

- 12:15–12:24：展示双侧卡扣与单侧活动卡扣的区别。
- 12:25–12:33：插槽凸起和内存缺口对应。
- 12:34–12:35：内存先放入插槽。
- 12:36–12:41：按压两端直到插紧。
- 12:42–12:45：字幕与画面确认卡扣自动闭合。

原实现：放入后点击卡扣，内存从 seated 变为 locked，但两状态高度相同。

本轮实现：

1. 保留旋转、缺口对齐、任意顺序及任意内存与插槽映射。
2. 左键放入后保持未压紧状态，模型比压紧位置高 8 个场景单位。
3. 准星对准顶部显示可按压提示；左键按下后模型下移，卡扣自动闭合并播放已有卡扣音效。
4. 未压紧时，侧面仍可拿起；卡扣不能代替顶部按压动作。
5. 压紧后需先打开卡扣，再取出内存。
6. 使用现有 seated/locked 状态，不改存档版本。新增 memory-press 动作，保留旧 memory-lock 动作兼容既有调用。

交互中的单次点击代表双手均匀按压，是产品简化；并未模拟真实施力、单端歪斜或手部。当前模型仍使用双侧联动卡扣，尚未按型号区分单侧活动卡扣。

### CPU

- 08:55–08:59：黑色塑料保护盖用于保护插座针脚，字幕说明安装时不必提前摘取。
- 09:03–09:09：先释放金属压杆，再抬起压盖。
- 09:11–09:33：插座定位凸起与 CPU 缺口对应，CPU 垂直放入。
- 09:39–09:51：放回金属压盖，再压下并扣住压杆。
- 09:53–09:59：黑色保护盖在扣合过程中弹出后取走。

原实现用 socketOpen 一个布尔值同时驱动压盖与压杆，模型也没有独立保护盖。

第二轮已实现压杆与金属压盖的独立操作：

- 当前目录的 AM5 主板：释放压杆 → 打开压盖 → 放入 CPU → 合上压盖 → 锁杆。解锁和取出按相反顺序操作。
- 当前目录的 AM4 主板：隐藏金属压盖，使用释放压杆 → 放入 CPU → 锁杆的交互，不要求操作不存在的压盖。
- socketOpen 保留为原字段，新增可选 socketLeverOpen。旧存档没有该字段时按原联动状态解释；原 socket-open/cpu-lock 联动动作保留兼容 AM4 和已有调用。
- 合盖但未锁杆时 CPU 仍为 seated；不能涂硅脂、直接取出 CPU，或搬动有未固定部件的主板。
- 压杆未释放不能开盖，盖未闭合不能锁杆；散热器和关闭的侧板阻止扣具操作。
- 更换主板重置扣具。每个中间状态可由 API 保存并读取。

本轮只完善现有简化模型的扣具交互，没有新增塑料保护盖、保护盖弹出动画或宣称模型精确还原某块实体主板。视频中的 Intel LGA1200 演示不等同于全部 AMD/Intel 插座，后续仍需按型号补充结构。

### 风冷

- 20:50–21:08：本段演示的散热器不使用原塑料卡座，拆下卡座但保留主板背面的背板；字幕同时指出部分散热器使用原卡座。
- 21:11–21:38：安装垫柱、适配支架和长螺丝。
- 21:41 起：涂硅脂。
- 22:25–22:41：检查并撕掉散热器底座保护膜。
- 22:45–23:09：散热塔落位，弹簧螺丝略施压力后咬合，两侧交替拧紧，避免先拧完一侧造成倾斜。
- 23:15–23:31：通过电机支架辨认出风侧，风向从内存侧流向后置接口侧。
- 23:33–23:43：钢丝扣先挂入风扇角孔，风扇贴到散热塔，再将钢丝扣扣到塔体。
- 23:45–23:59：另一侧风扇采用相同风向，重复固定动作。
- 24:01–24:17：连接风扇线，区分 CPU 风扇接口与其他接口。

第三轮已拆分散热塔与双侧风扇：

- 新选配的散热器以散热塔和两只独立风扇出现在推车上。风扇可左键拿放、旋转、放在工作台或其他可用落点。
- 对准对应侧面放入风扇后为贴合状态，再点击顶部钢丝扣固定；松扣后可从风扇本体拿下。
- 左右侧安装没有先后要求，也可以在散热塔装上主板前预装。两只风扇同向，模型增加出风侧电机支架。
- 有已贴合但未扣紧的风扇时不能搬动组件；接线前两侧必须固定。拆卸须先拔线，机箱侧板关闭时不能操作机内风扇。
- 新增可选 coolerFans 状态，旧存档缺失时解释为两侧均已固定，保留原有整件散热器行为。更换散热器前需将散热塔和两只风扇都归还推车。

产品简化：左右风扇对应各自安装位；每次扣具点击代表该风扇的两根钢丝扣一起操作；接线仍使用一个 fanConnected 状态，未拆分每根风扇线或模拟布线。底座保护膜、分次拧紧和支架背板见后续轮次记录。

钢丝扣外形修订：重新对照 23:33–23:43 和 23:55–23:59 的已有截图，将直杆改为圆截面钢丝，补充角孔挂钩、斜向拉臂和中段折弯拉手。两侧镜像朝向散热塔，松扣时绕风扇挂点向外张开，取代整体平移。此处按画面轮廓近似建模，并非实物尺寸复刻。浏览器已验证松扣与回扣，无控制台错误。

第四轮已实现底座保护膜与分次拧紧：

- 新选配的散热器附带半透明蓝色底膜和外露拉片，空手左键点击拉片移除；已落位时底座被 CPU 遮住，需先取下散热器。
- 带膜仍允许落位和接线，但这两个动作会明确提醒未撕膜，避免把教学建议变为强制顺序。
- 每侧螺丝用三个深度表示逐步拧入，每次按住左键完成一段，模型随深度下降。推荐两侧交替，但允许任意一侧先完成，不模拟实际扭矩或散热塔倾斜。
- 部分拧入也会阻止直接拿走散热器；两侧完全固定后才能接线和搬动主板组件。松开动作仍是一次完成，不是渐进旋出；页面部分拧入阶段继续拧紧，完全拧紧后可松开。
- 保留原 cooler-screw 整次固定动作兼容旧调用，页面使用 cooler-screw-step。coolerScrewDepths 缺失时从旧布尔固定状态推导；coolerFilm 缺失时按已移除解释，不给旧存档补膜。更换散热器重置保护膜和深度。
- 本轮没有新增支架或背板，也没有模拟撕膜变形、温度或实际散热后果。

推荐顺序只作引导。缺少保护膜移除等不会造成几何阻挡的情况，应与物理无法安装的情况区分，后续通过提醒及验机反馈表达，避免所有教学步骤都成为强制前置条件。

- 全量 84 项测试通过，前端构建通过。
- 浏览器通过实际左键点击确认顶部提示、按压成功反馈与模型落位，以及从侧面拿起跨槽放入的第二根内存；无控制台错误。锁定后的拆卸与存档规则由自动测试覆盖。

第二轮验证：新增 5 项 CPU 扣具测试，全量 89 项通过，前端构建通过。浏览器已实际验证 AM5 锁杆、释放压杆、打开压盖，以及未释放压杆时无法开盖的反馈；AM4 不显示压盖，释放压杆后提示可以放入或取出 CPU，无控制台错误。

第三轮验证：新增 8 项风扇测试，全量 97 项通过，前端构建和格式检查通过。覆盖自由顺序、组件移动限制、拔线拆卸、侧板遮挡、归还推车、更换型号、旧存档、非法状态、API 保存读取及模型批处理。浏览器实际完成两侧扣紧、右侧风扇拿起和贴合、松扣后取下并自由放回桌面；无控制台错误。

CPU 塑料保护盖，以及上述未完成的风冷安装细节仍是后续工作，不代表已经交付。

第四轮验证：新增 5 项测试，全量 102 项通过，构建与格式检查通过。覆盖撕膜和带膜安装、任意侧先拧紧、部分咬合禁止拿走、松开、旧存档、非法深度、新型号重置及 API 保存恢复。浏览器实际完成撕膜，确认已保存的 1/3 深度能恢复并显示交替拧紧提示，无控制台错误；完整三阶段状态转换由自动测试覆盖。


### 第五轮：原卡座、散热支架和保留背板

当前目录均为 AMD AM4/AM5 主板。本轮对照视频 20:50–21:44 的原卡座拆卸、垫柱、支架和四颗长螺丝，并核对 [Noctua 官方 AMD 背板说明](https://www.noctua.at/cn/support/faqs/does-my-amd-motherboard-come-with-a-backplate-and-how-do-i-proceed-with-the-installation)：AM5 原背板固定在插座上，应保留；所参考的这类支架直接使用原背板螺纹。该说明用于核对安装结构，目录中的演示散热器并非该品牌实物复刻。

- 新选配主板附带两条原塑料卡座，每条两颗螺丝；主板背面增加绝缘层、背板和四个螺纹支点。
- 螺丝刀长按松开两端螺丝，再空手左键拿走卡座，可自由放在桌面、推车或其他合法落点。
- 选配散热器同时提供两条独立金属支架，每条与两个垫柱作为一个拿放单元；对准空出的同侧安装位落位，再用两端螺丝固定。
- 左右侧任选先做，CPU 安装没有前置关系。原卡座不能与新支架占用同一个位置。四颗支架螺丝都固定后才能放下散热塔。
- 散热塔遮挡时不能拆动下方支架，关闭的机箱侧板阻挡内部操作；有未固定支架时不能搬动主板组件。
- 支架装在主板上时，禁止更换主板或散热器；拆下并放回推车后可更换。原卡座可固定在主板上一同归还，或拆下单独归还。
- 可选 mounting 状态缺失的旧存档按散热支架已固定解释，后续拆卸时补齐实体摆放位置。新选配会初始化原卡座或对应散热支架。

简化范围：背板保留在主板上，不作为独立拿取件；AM4 原卡座拆除后需要托住背板的动作尚未模拟。垫柱未单独拿放，长螺丝随卡座/支架移动，不模拟完全取出的散落螺丝。模型表现通用结构，未精确复制视频中支架的曲线及尺寸。

验证：新增 5 项支架测试，全量 107 项通过，构建和格式检查通过。覆盖任意侧先做、CPU 未安装时预装、螺丝及遮挡约束、自由落点、选配更换、旧状态兼容、非法状态和 API 保存恢复。既有风扇及保护膜测试改为先通过真实动作完成支架准备。新增背板几何已更新模型基线，原绘制数量上限仍通过。浏览器实际完成松开状态卡座的拿起、桌面放下、支架拿起与主板落位，控制台无错误；长按固定及反向拆卸状态由自动测试覆盖。
