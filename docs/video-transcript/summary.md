## 1. 视频的核心讲法

视频先介绍配件作用，再逐项展示定位、对齐、插入、固定和接线，最后验证是否成功开机。它反复解释每个动作的原因：缺口用于防止装反，卡扣表示安装到位，螺丝柱隔开电路板与金属机箱，保护膜影响导热，线缆和接口的对应关系决定设备能否工作。

教程中的推荐顺序有助于避开空间遮挡，但不同机箱、主板、散热器的安装方式可能不同；视频多次要求按对应型号的说明书操作。适合提炼成模拟器规则的是部件之间的机械依赖、接口匹配和异常反馈。

## 3. 最值得保留的安装细节

**CPU 与内存：正确朝向、到位和锁定是不同状态。** CPU 要先释放对应扣具，再按插座定位结构垂直放入；LGA 类保护盖与扣合过程有关。内存放进槽里还不等于插到底，教程明确强调按两端，卡扣自动闭合。型号和插槽代际决定是否匹配。

**M.2：安装涉及支撑高度和覆盖件。** 14:25–16:59 讲了斜插、尾部螺丝柱、硬盘长度和水平固定；导热垫保护膜要处理，硬盘本身的型号贴纸不是同一种东西。16:59–19:07 继续讲接口协议、CPU/芯片组通道及与 SATA 的复用，说明“外形能插入”和“型号能够识别”需要分别判断。

**散热：扣具、接触和风道共同决定结果。** 视频示例中的 AMD 风冷需要拆原卡座并保留背板，Intel 示例使用相应散热器背板；这不是所有产品通用的安装方式。21:37–23:08 重点解释硅脂、底膜和弹簧螺丝交替下降。23:11–25:20 则说明风扇朝向、钢丝扣及接线：两个风扇应配合形成连续风道；CPU_FAN、辅助风扇及水泵接口的默认控制策略可能不同。

**主板入箱：铜柱和挡板应成为实际部件。** 28:04–31:32 的重点是先确认 I/O 挡板，再让铜柱与主板安装孔对应。多余铜柱可能碰到电路板背面，缺少支撑也会造成问题；主板不能直接贴在机箱金属板上。孔数取决于具体板型，视频示例的九孔不能直接推广到所有主板。

**接线：不仅要分清线名，还要表现接头结构。** 视频展示了卡扣、凸起、缺针和组合插头。模组线有电源端与配件端，53:36–53:54 特别强调不同电源的模组线不能随意混用。前面板开关和指示灯有不同极性要求，USB、音频、Type-C 也各有防呆结构。

**显卡：安装前的准备与安装后供电都不可省略。** 先比对占用的机箱挡板，再打开卡扣、插入、固定。供电按显卡接口要求连接；视频中的特定分线和功率数字属于其示例讨论，应结合具体电源、显卡和线缆说明理解。

**开机：通电、通过自检和进入系统是不同阶段。** 风扇转动只能说明有通电迹象；还要查看画面、自检提示、启动设备和系统情况。视频介绍了调试灯，但模拟器不能把某一盏灯简单当作“某个零件肯定损坏”，它更适合表示一个需要排查的环节。

## 4. 对我们装机工具的建议

以下是从全文得到的产品建议，本次只整理文字，没有继续修改程序。

### 优先补齐完整装机闭环

1. **主板入箱准备**：增加铜柱与独立 I/O 挡板，按具体主板孔位配置；落位前显示实际干涉位置。
2. **前面板线缆**：从机箱拉出 POWER SW、RESET SW、状态灯、USB 和音频线，让接线真正影响按钮、灯和接口能否工作。
3. **首次开机与排查**：用机箱上的实体按钮触发通电和自检，结合主板调试灯、风扇运行和简洁的检查结果提示，让用户能发现并修正错误。无需恢复此前删除的四角按钮，也不必把显示器重新摆回工作台。

### 然后扩充装配分支

4. **M.2 深化**：增加独立散热片、导热垫保护膜、长度对应的螺丝柱，以及型号支持的快装卡扣。
5. **SATA 硬盘**：加入硬盘托架、数据线和供电线，表现“只接数据线或只接电源都不完整”。
6. **机箱风道与水冷**：先完善机箱风扇、占位和风向，再加入冷排、冷头及水泵；避免只增加一个外观模型。

### 统一交互规则

- 推荐顺序用于提示，不用全局任务清单锁死下一步。
- 物理阻挡要直接限制：安装位被占用、卡扣未打开、螺丝仍固定、侧板遮挡等。
- 未撕膜、散热接触不充分等问题适合通过验机或运行反馈表达；必要的缺件、缺供电也应在自检阶段有对应结果。
- 对准可操作位置才提示，继续以左键拿放/操作为主。
- 支架、垫柱、螺丝、线缆、托架与挡板是否拆分，应取决于它是否能让用户理解一个关键安装动作。
- 再核对现有双风扇朝向与内存侧、后置 I/O 侧的对应关系；不仅要让两个风扇同向，还要让整体风道正确。

## 5. 不宜直接固化为通用规则的内容
